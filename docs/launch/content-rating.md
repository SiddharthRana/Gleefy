# Content rating (IARC questionnaire notes)

Play Console → App content → Content rating runs the IARC questionnaire. These answers reflect the shipped packs (checked 2026-11-03 by scanning all four packs for violence, sexual, drug, alcohol and gambling terms: only biology and plain historical mentions such as "Second World War" and "red blood cells").

| Questionnaire area                              | Answer | Why                                                                       |
| ----------------------------------------------- | ------ | ------------------------------------------------------------------------- |
| Category                                        | Game   | A trivia and party game                                                   |
| Violence (realistic, fantasy, blood)            | No     | No violent content. Trivia mentions historical wars and biology factually |
| Fear / horror                                   | No     |                                                                           |
| Sexuality, nudity, sexual innuendo              | No     |                                                                           |
| Language (profanity, crude humour)              | No     |                                                                           |
| Controlled substances (drugs, alcohol, tobacco) | No     | Food questions only                                                       |
| Gambling (real or simulated)                    | No     | Points only; no betting, wagering or loot boxes                           |
| Users can interact or communicate               | No     | No chat or user-generated content; games are played in person             |
| Shares the user's location                      | No     |                                                                           |
| Digital purchases                               | Yes    | Optional one-time Premium unlock (Google Play)                            |
| Unrestricted internet access                    | No     | Links open the website, Google sign-in or Google Play only                |
| Miscellaneous: crude/discriminatory humour      | No     | Content guidelines (BUILD_PROMPT §7) forbid it                            |

Expected outcome: the lowest age bands (e.g. PEGI 3 / ESRB Everyone), with an "In-app purchases" notice. The app's own guidance stays **13+** (some Would You Rather categories are marked 13+ for discussion topics) and the Play target audience is 13+, which is separate from the IARC rating.

Redo the questionnaire whenever a new pack or category could change an answer (for example, anything about dating, alcohol or scary stories).
